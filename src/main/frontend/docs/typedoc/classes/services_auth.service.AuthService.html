    Class AuthService

    Handles authentication state for the BoatFleet application.

    Credentials are validated client-side (any non-empty username/password succeeds). The authenticated user is persisted in sessionStorage so that a page refresh does not force a re-login within the same browser tab.

    Example

    const auth = inject(AuthService);

    if (auth.login('admin', 'secret')) {
      router.navigate(['/boats']);
    }

    // Later…
    auth.logout();
